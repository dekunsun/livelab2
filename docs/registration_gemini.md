## 问题

主运行（Opus 5.5）里有两条和 1.0 一脉相承的发现：原始数据没盖住起点时，模型仍报精确秒数而不说“在我看到的数据之前”（P5）；对注入无故障运行的假告警，模型多数照样报起点（P6 不成立）。这是 Opus 一家的行为，还是普遍现象？另一条“模型自己选窗口和真值选窗一样准”（P3 不成立）是否也普遍？

## 模型

`gemini-3.1-pro-preview`，Google 原生接口（generateContent），函数调用 AUTO，不强制；系统提示、工具、题目和 Opus 完全相同；思考 token 按输出计价（US$2 / US$12 每百万）。选它的理由：1.0 里写明规则后与 Opus 5.5 最接近的另一家前沿模型（79 对 80），能力对等，比较才有意义。

已知限制：该模型付费层每天 250 次请求（1.0 记录，太平洋时间零点重置）。D 组每题最多 6 次请求，整轮约 600 次，预计跨 2–3 天完成。运行器遇到当天配额用尽即停、不写记录、次日用同一命令续跑；每题的各格连着跑，跨天的中断落在题与题之间。
